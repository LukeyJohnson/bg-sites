**Integrated PDF markup workspace. **
A full in-product PDF viewer now bundles zoom, markup overlays, split-screen actions, and pin visibility controls so teams can review drawings without leaving the app.

![2025-10-28 15.19.39.png-9135](https://storage.sleekplan.com/products/287727888/changelog/50603/inline-1092590da86874c97dd5c962fa66feae.jpg)

** Folder Managements arrives in Horizon CDE. **
Project-scoped folder trees, lazy loading, and a documents/transmittals toggle make it much easier to organise large document sets.

**Uploads are now project-aware and metadata-safe. **
The refreshed Horizon uploader deduplicates metadata requirements, supports drag/drop, and pushes optimistic updates while targeting specific projects or folders.

**Expiry-aware document listings. **
CDE tables surface expiry metadata alongside type and version badges—automated compliance reminders.

**DS Site form to Document capture sync. **
DS Site Forms can be used to collect documents into the CDE automatically! Very useful for subcontractor management workflows.

**Markup tools add “Pin Action” (beta) **
The redesigned toolbar introduces polygons, rectangles, text, and a new pin mode for associating actions directly with locations on the plan.

**Transmittals hub (beta). **
The new manager handles creation, WBS tagging, document selection, recipient management, and send/track flows to prepare for formal transmittal workflows.
