## What’s new

### Explorer
- The original *Documents* tab is now **Explorer**
- Continue to browse, search, upload, and organise project files in the same familiar interface

### Document Register
- A new tab dedicated to registered documents
- Shows latest issue dates and recipients automatically derived from transmittals

### Promote to Register
- New toolbar action in Explorer
- Converts a document into a controlled record
- Opens a metadata modal requiring all register fields before saving

### Transmittal Guardrails
- Transmittals now block unregistered documents
- Only fully registered, metadata-complete documents can be issued

## Benefits
- Faster switching between general file management (Explorer) and controlled document records (Register)
- Required metadata captured at the moment of promotion—reducing rework and audit gaps
- Outbound transmittals remain compliant and consistent across all projects

## Why this matters
- **Cleaner navigation for project teams:** The former *Project Documents* area is now split into an **Explorer** for everyday file browsing and a dedicated **Document Register** for controlled records.
- **Consistent document control:** Registering a document now captures standard control fields (number, revision, status, title, type) to align Deep Space Horizon with industry metadata practices.
- **Higher-quality transmittals:** Only registered documents can be issued externally, ensuring all outbound packages include complete register metadata.
