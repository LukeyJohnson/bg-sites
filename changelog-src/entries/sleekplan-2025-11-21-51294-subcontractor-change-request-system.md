Overview

We've launched a comprehensive change request system that enables subcontractors to propose schedule and progress modifications directly within the platform. This feature streamlines the communication process between subcontractors and project managers, providing a structured workflow for handling schedule changes with proper approval mechanisms.

Why We Built This

Previously, subcontractors had to rely on external communication channels (emails, phone calls, or meetings) to request changes to their task schedules or progress updates. This often led to:

- Communication gaps between subcontractors and project managers
- Delayed decision-making due to scattered change requests
- Lost documentation of change rationales and approvals
- Inconsistent tracking of schedule modifications across projects

  Our new change request system addresses these pain points by providing a centralized, transparent, and auditable process for managing schedule changes.

  How It Works

  For Subcontractors

  1. Access Task Details: Click on any task in the Gantt chart from the Lookahead Planning view
  2. Submit Change Request: Expand the "Request a Program Change" section in the task modal
  3. Specify Changes: Modify start date, end date, and/or progress percentage as needed
  4. Provide Justification: Add a detailed reason explaining why the change is necessary
  5. Track Status: Monitor request status with visual indicators (yellow highlighting for pending requests)
  6. Cancel if Needed: Cancel pending requests using the integrated cancel button
  ![101919192.png-2099](https://storage.sleekplan.com/products/287727888/changelog/51294/inline-a154a643e49d3b426d4eb6907a8cbeb3.jpg)

  For Project Managers

  1. Review Requests: View change requests in the Task Detail Sidebar with clear pending indicators
  2. Evaluate Details: Access comprehensive information including requested changes and reasoning
  3. Make Decision: Approve or reject requests using the streamlined action buttons
  4. Provide Feedback: Add optional approval or rejection reasons for better communication
  5. Apply Changes: Approved changes are automatically applied to the task schedule
  ![10100282822.png-6390](https://storage.sleekplan.com/products/287727888/changelog/51294/inline-4617e5827a9739bf2ac58f03407273d9.jpg)

This system ensures that all schedule modifications are properly documented, reviewed, and implemented through a transparent approval process, improving project coordination and accountability.
