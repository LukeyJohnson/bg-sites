## What's New

You can now bulk import budget categories from an Excel file, making it faster to set up your cost structure.
![1fe59f60cc159ec62de0d588d1e39e03.png-5014](https://storage.sleekplan.com/products/287727888/changelog/51623/inline-1f923fe9657500d83916f9709f977bd7.jpg)
### How to use

1. Click the **Import** button in Budget Categories
2. Download the Excel template
3. Fill in your categories (Category ID, Name, Description)
4. Upload the completed file
5. Review and select Type (Direct/Indirect) for each category
6. Click **Create** to import all categories at once
![aae02e0dd8e94d1d8b1b68c0062f44ad.png-4031](https://storage.sleekplan.com/products/287727888/changelog/51623/inline-e2aeebc7b64a4b729d64edeeb9b3ea26.jpg)

- **Excel export** - Export your budget categories to Excel (.xlsx) in addition to CSV
