Locations on construction projects usually end up messy - “Level 2”, “L2”, “Second Floor”, all meaning the same thing. Over time that breaks reporting and makes site data unreliable.

Deep Space now supports a Location Breakdown Structure (LBS).

LBS lets you define a project-specific location hierarchy (site → building → level → area / room) in Project Settings. This becomes the single source of truth for where things happen on the project.

Once set up, locations are used consistently across Deep Space.
When logging Actions, Defects, RFIs, inspections, safety items, or site forms, users select a location from the project’s LBS instead of typing free text.

The result:
	•	Cleaner, more consistent site data
	•	Faster form completion for site teams
	•	Meaningful location-based filtering and reporting
	•	Clear visibility into where issues are actually occurring

It’s a small setup step that quietly improves almost every workflow.
