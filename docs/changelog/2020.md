### 1.0.47 Deep Space Sync for Revit Enhancements
* Simultaneous data capture and upload - improved Sync performance
* Global Consistency of Project Unit parameter data storage
* Collection of Revit Project Units metadata
* Collection of Monitored Elements (Copy / Monitor API)
* New option to exclude capture of Revit Parameters from Annotation elements
* Progress Bar improved, providing more detail on Sync process
* Capture Point Cloud reference data, stored in federated_links schema as PointCloudType
* Added storage of Revit Central File Name and Location for workshared models
* Added storage of LastAlias (last Filename for this cloud entity)
* Added collection of Revit Link Instance data for Sheets and Views
* Improved ability to cancel Sync and rollback data upload
* Consistency of data capture improved
* Performance and Bug Fixes

### 1.0.47 Web Updates
* Visual, Workflow and UX improvements
* Project User and Workspace Manager (Admin) permissions clearly separated
* Intercom added to Workspace Manager
