# PM Grid

<p class="bg-lead">AI-assisted project management in a high-density, monochrome grid.</p>

</div>

[Open PM Grid :material-open-in-new:](https://pmgrid.blackgrid.com.au/){ .md-button .md-button--primary }

PM Grid is built for people who run many projects at once and want to move between projects, events and tasks without losing context.

## Core features

- **Multi-column grid interface:** a four-column, fixed-width layout for navigating projects, events and tasks side by side.
- **Modular DataBlocks:** flexible Markdown or JSON content containers that can be linked and shared across projects and events.
- **Global context selection:** select any element as context for the AI agent.
- **AI action tool:** analyses the selected DataBlocks and generates structured tasks, events and linked blocks.
- **Unified workspace management:** contacts, tags and custom event types managed globally with real-time sync.
- **Sharing and permissions:** invite-only project access with viewer and editor roles.
- **Google sign-in** for onboarding.
